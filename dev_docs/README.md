# `dev_docs/` in this repo

The layout follows `dev_docs_layout.md` at the plugin root. This file lists
only what this repo has. This repo also holds the canonical copies of the
directory READMEs that other repos copy.

| Path             | This repo keeps here                                                                    |
| ---------------- | --------------------------------------------------------------------------------------- |
| `conventions.md` | the live description of how the reviewing and authoring conventions are built           |
| `designs/`       | proposals for changes to the plugin's shape, deleted once they land                     |
| `decisions/`     | why the plugin is shaped as it is, one record per choice                                |
| `research/`      | the evidence behind designs and decisions                                               |
| `.handoffs/`     | session-to-session notes, gitignored; its `README.md` says why that one file is tracked |

No `tasks/`: this repo files issues on GitHub and has no plan scaffolding yet.
