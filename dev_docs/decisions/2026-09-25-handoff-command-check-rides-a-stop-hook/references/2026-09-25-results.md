## Live `Stop` probe, Claude Code 2.1.282

A throwaway plugin carried only this hook, with a wrapper that appended each
payload and each hook output to a file. `claude -p --model haiku --plugin-dir
<that plugin>` was told to reply with one 142-character `! gh api …` line and
use no tools.

- The hook fired twice. Payload keys, both times: `background_tasks`, `cwd`,
  `hook_event_name`, `last_assistant_message`, `permission_mode`, `prompt_id`,
  `session_crons`, `session_id`, `stop_hook_active`, `transcript_path`.
- First call: `stop_hook_active` false, `last_assistant_message` the long
  line. The hook returned `decision: block` naming the 142 characters.
- Second call: `stop_hook_active` true, `last_assistant_message` the model's
  reply to the block reason. The hook returned nothing.
- The run reported `num_turns: 2`. With no tools it could not move the path,
  so it said the command had to be shortened or scripted instead.

A documentation read the same day reported that `Stop` "cannot block" and
listed neither `stop_hook_active` nor `last_assistant_message`. The probe
contradicts all three claims.
